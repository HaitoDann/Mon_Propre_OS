# ADR 0006-firefox-esr — Firefox ESR via APT

- **Statut** : accepté
- **Date** : 2026-11-09

## Contexte
Firefox doit être préinstallé, de façon cohérente avec la priorité donnée à la stabilité.

## Décision
Firefox ESR depuis les dépôts Debian pour la première version.

## Conséquences
Mises à jour de sécurité Debian ; fonctionnalités en retrait par rapport à la version rapide. Décision à revoir plus tard.
