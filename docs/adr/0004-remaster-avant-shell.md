# ADR 0004-remaster-avant-shell — Remaster thémé avant le shell maison

- **Statut** : accepté
- **Date** : 2026-11-09

## Contexte
Un shell maison prend des mois ; il faut un produit utilisable tôt.

## Décision
La phase 1 livre une ISO basée sur un Plasma minimal thémé. Les composants maison le remplacent ensuite progressivement.

## Conséquences
Une ISO utilisable rapidement, et une chaîne de construction validée avant le gros développement.
