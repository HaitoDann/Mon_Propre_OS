# Branding

Tout le visuel est défini ici : `brand.toml` (nom, couleurs, polices, formes, animations), et à venir `logo/`, fonds d'écran, icônes, thèmes Plymouth, GRUB, SDDM et Calamares.
Pour renommer l'OS ou changer ses couleurs, on ne modifie que ce dossier.

## Fichiers

| Fichier | Rôle |
|---|---|
| `brand.toml` | Nom, version, couleurs principales, chemins des logos |
| `tokens.toml` | Design tokens complets (couleurs par thème, typo, espacements, rayons, durées) → `Theme.qml` |
| `icons/` | Jeu d'icônes SVG du système |
| `logo/`, `wallpaper/`, `boot/` | Logos, fonds d'écran, écrans de démarrage |
